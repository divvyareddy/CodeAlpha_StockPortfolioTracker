# Stock Portfolio Tracker
## Description
This project was developed as part of the CodeAlpha Python Internship.
It allows the user to enter stock names and quantities, calculates the investment value using predefined stock prices, and saves the total investment in a text file.
## Features
- User enters stock name and quantity
- Calculates investment value
- Displays total investment
- Saves the result in `portfolio.txt`
## Technologies Used
- Python
## How to Run
1. Open the project in VS Code.
2. Open the terminal.
3. Run:
```bash
python main.py
```
